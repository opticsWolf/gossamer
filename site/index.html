Why gossamer

Deterministic where it counts,
flexible where it matters.

Parsing, guards, budgets, and citations run in Rust — byte-identical every time. Search strategy, caching, and routing stay in Python, where iteration is cheap.

⚡

Rust parsing core

Response parsers, HTML metadata, SSRF/robots, budgets, citations, and scoring in _core (PyO3) — with differential parity tests against Python oracles.

📄

Documents, all of them

PDF, DOCX, XLSX, PPTX plus legacy DOC/XLS/PPT/XLSB, feeds, and office formats — tables as markdown, figures on demand with store=True.

🔬

JATS-first scholarship

DOI-resolvable papers take publisher full-text XML first (EuropePMC / PMC OA / PLOS) through the in-house kernel — fused math, \tag{} displays, real GFM tables.

🕸️

Bounded smart crawl

Relevance-ranked BFS with BM25 idfs, thesaurus expansion, and anchor context. Documents collected, never fetched blindly.

📚

Citations for free

BibTeX, CSL-JSON, APA, and MLA straight from search results — deduped, no extra network calls.

🛡️

Production posture

TTL + size-cap caching, per-domain rate limits, robots/SSRF compliance, retries, and an optional JailGuard injection detector.

Quick start

Running in five minutes.

Rust 1.82+, Python 3.10+, maturin. Hermetic tests by default — no network, no models.

# clone, install deps, build the Rust core
git clone https://github.com/opticsWolf/gossamer && cd gossamer
pip install -r requirements.txt
maturin develop --release
# optional extras: browser rendering, MCP server, injection guard
pip install -e ".[browser,mcp,guard]"
from gossamer import ToolboxConfig, WebResearcherToolbox

tools = WebResearcherToolbox(ToolboxConfig(cache_dir="./cache"))
results = tools.web_search("latest AI research papers", max_results=5, search_only=True)
paper = tools.extract_document("10.1371/journal.pone.0306040") # JATS-first
cited = tools.export_citations(results, style="bibtex")
# *_async offloads the blocking core to a thread pool —
# the event loop stays responsive, I/O stays synchronous.
results = await tools.search_web_async("rust programming")

Harness integration

Same server, every agent.

One stdio server (python -m gossamer.mcp_server), keys in the keystore — never in client configs. Shallowest first: CLI → MCP → bundled skill.
